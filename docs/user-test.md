# Real-user test

Scripted evals show whether the model's behavior changes. This shows whether that change actually helps a person decide something. Run it with five people before spending more time on the skill.

## Setup

1. Ask each person for a real AI conversation from the past month that went in circles: a decision they were trying to make, where they ended up more confused than when they started.
2. Have them install Anchor (or paste the system prompt) and restart that same decision from scratch.
3. Let them talk for 15 to 20 minutes however they like. Don't coach them.

## Afterwards, ask

1. Did you come out with a decision? What was it?
2. Compared with the original conversation, was this faster, slower, or about the same?
3. Was there a moment it annoyed you? When?
4. Did it ever tell you to start a fresh chat? Did you? What happened?
5. Would you leave it switched on?

## Decide

- **Keep going** if at least 2 of 5 say it helped them reach a decision faster.
- **Stop** if fewer than 2 do. Write down why, and don't keep tuning the prompt in the hope it gets there.
